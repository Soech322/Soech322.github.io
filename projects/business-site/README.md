# Fieldwork

A responsive service website for a fictional garden studio. Clear services, accessible navigation, and a local inquiry demo.

**Project type:** self-initiated demonstration, created with AI assistance. Not paid client work.

**Skills:** HTML · CSS · Web development

## Problem and approach

A small service business needs visitors to understand its services and make an inquiry. This fictional studio concept uses semantic sections, responsive layouts, accessible form labels, native validation, and an inquiry preview. The form does not send messages.

## Run

From the repository root with Node.js 20+:

~~~sh
npm start
~~~

Open `http://127.0.0.1:4173/projects/business-site/`. No package installation or build step is required.

## Demo

[Open the interactive demo](https://Soech322.github.io/projects/business-site/)

## Limitations

Fictional business content; no booking service, backend, or email delivery.

## What to demonstrate to a client

Resize the page, follow the service links, and preview an inquiry.
