05 / PYTHON & WEBSITE MAINTENANCE

Find the links
that lead nowhere.

A standard-library command-line utility for checking a small website's internal links.

RUN LOCALLY / PYTHON 3.10+
python check_links.py https://example.com \
  --max-pages 25 --output report.json

Downloads HTML pages, follows same-origin links, and writes a JSON report with HTTP status, discovery source, and errors.

Get the Python source ↗
This page explains the tool. It does not run a crawler or contact a website from your browser.
ILLUSTRATIVE REPORT
/200 OK
/services200 OK
/old-contact404 Not Found

Small by design.

  • Same-origin crawling with a request limit and timeout.
  • Fragments, mail links, and external URLs are skipped.
  • JSON report and a non-zero exit code for detected failures.
  • Tests run against a local HTTP fixture.

Use on sites you own or have permission to check. This is a small-site diagnostic, not a full SEO or security audit.
